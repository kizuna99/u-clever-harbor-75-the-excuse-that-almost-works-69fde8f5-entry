This entry is a small Python program for the make.fun bounty "The Excuse That Almost Works". Running `main.py` produces exactly one line in `/output/entry.txt`: a rushed, plausible-sounding text to a boss about a leaking kitchen tap, a plumber whose only free slot happens to be today, and neighbours downstairs who have already complained twice. Before writing, the program checks the line against the gate limits (a single line, at most 140 characters and 20 words), and after writing it reads the file back to confirm the bytes on disk match what was validated.
